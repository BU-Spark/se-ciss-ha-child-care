# CCR&R required paperwork

Place agency PDF packets here so the Resources tab can link to them.

## Expected filenames (from EEC client materials)

| Agency | File |
|--------|------|
| Child Care Choices of Boston | `child-care-choices-of-boston.pdf` |
| Seven Hills Child Care Resources | `seven-hills-child-care-resources.pdf` |

After uploading a PDF, set that agency’s `paperworkStatus` to `"available"` in
`src/config/ccrr-agencies.ts`.

Additional CCR&R packets will be added when the state provides them.
